# 실험 데이터 보호 방침

기준일: 2026-11-10. 구현에서 확인한 보호 경계와 운영자가 적용해야 할 조치를 구분한다.
관련 점검 수치·예외는 [보안 점검 결과](security_check.md)를 따른다.

## 1. 데이터와 목적

| 자료 | 포함할 수 있는 정보 | 처리 목적·공개 전 주의 |
|---|---|---|
| 요청 JSONL | 요청 ID, 입력·출력 토큰 ID, 시각, 처리 장치·주소, 오류 | 지연·처리량 재계산. 토큰 ID로 내용을 복원할 수 있어 익명 자료로 간주하지 않음 |
| 서비스·실행 설정 | 모델·캐시·venv 경로, argv, 역할별 환경, 엔드포인트 | 재현성 확인. 사용자명·호스트·설치 경로·민감 환경변수 검토 |
| 서비스 로그 | 예외, 라이브러리 버전, 경로, 장치 식별자, 요청 관련 정보 | 실패 원인 분석. 원본 로그 전체를 공개 보고서에 복사하지 않음 |
| metrics·links | CPU·메모리·전력, GPU UUID, NPU PCI ID, 시스템 정보 | 장치 대응·자원 분석. 하드웨어 식별자와 운영 패턴은 공개 범위 검토 |
| OTEL·엔진 이벤트 | 요청 ID, 서비스명, 시간 anchor, KV 전송·실행 구간 | 요청 매칭·단계 분석. 토큰 내용과 결합할 수 있는 식별 자료 |
| torch·RBLN trace | 연산 이름, tensor 관련 메타데이터, 경로, 프로세스·장치 정보 | 오프라인 연산 특성 분석. 대용량 원본은 납품 데이터셋에 포함하지 않음 |
| 집계 CSV·그림·보고서 | 성능·자원·에너지 통계, 모델·조건, 출처 | 납품용 요약. CSV 셀·그림 캡션에도 내부 경로가 남는지 확인 |
| QA 결과 | 패키지 목록, 취약점 ID, 코드 위치, 커밋 | 변경 추적. 감사 파일에 포함된 실행 환경 식별정보는 별도 검토 |

본 실험은 내부 측정용 입력을 전제로 한다. 임의의 실사용 프롬프트나 개인정보를 수집하도록 설계하지 않았다.
실제 민감 데이터가 없음을 프로그램이 자동 보증하거나 검출하지는 않는다.

## 2. 통신 경계

| 구성 요소 | 확인한 설정 | 운영 조치·미확인 사항 |
|---|---|---|
| B0/PDD vLLM 서버 | `orchestrate.py`에서 host 127.0.0.1 | 외부 포트 포워딩·역방향 proxy로 공개하지 않음 |
| toy proxy | 루프백 prefill·decoder, proxy host 127.0.0.1 | 같은 호스트 사용자도 접근 가능. 루프백은 인증 기능이 아님 |
| OTel Collector | `profiler/otelcol.yaml`의 OTLP HTTP 127.0.0.1, file exporter | 원자료는 지정 OTEL_OUT에 저장. 외부 exporter 설정을 추가하면 재검토 |
| all-smi | PC4 기준 0.0.0.0 바인드 (`tests/hetero/mock_protocol.py`의 실측 기록) | 예외 포트의 외부 접근을 방화벽으로 차단해야 함. 실제 방화벽 규칙 적용은 미확인 |
| scraper | 정상 runner는 로컬 endpoint 생성; 단독 CLI는 지정 URL 사용 | 운영자가 루프백 HTTP만 입력. 코드의 강제 allowlist는 없음 |
| Perfetto UI | 오프라인 번들 UI를 루프백 HTTP로 제공 가능 | 민감 trace는 로컬 UI에서만 열기. 온라인 UI·공유 기능 이용은 별도 승인·검토 |

프로파일러의 정상 설정에는 실험 자료를 외부 서비스로 전송하는 exporter·업로드 경로가 없다.
다만 전체 SDK의 부가 통신과 실제 네트워크 패킷을 검사하지 않았으므로 “외부 전송이 전혀 없다”는 실증으로 해석하지 않는다.
번들 제작은 릴리스·PyPI 다운로드, 보안 감사는 패키지명·버전 및 advisory 조회를 위해 인터넷을 사용한다.
이 작업은 실험 원자료 수집과 구분한다. 모델 파일은 운영자가 확보한 신뢰하는 로컬 스냅샷을 사용한다.

## 3. 저장·권한·공개

원자료·설치 산출물·로그는 저장소 밖의 운영자 지정 결과·설치 위치에 둔다.
서비스 파일은 `<service_run>/service/`, 프로파일러·workload 자료는 `<service_run>/` 아래에 저장한다.
개발 참고 `.notes/`와 `AGENTS.md`는 로컬 전용이며 커밋·납품에 포함하지 않는다.

현재 코드는 파일 암호화, 전용 ACL, 보존 기한, 자동 삭제를 강제하지 않는다.
운영자는 전용 계정·최소 권한 디렉터리·제한된 umask를 적용하고, 백업도 같은 접근 권한으로 관리한다.
모델·캐시·도구 실행 파일은 다른 사용자가 임의로 바꿀 수 없게 한다.
환경 파일에는 실행 파일 경로 등 운영 정보가 있으므로 문서·QA 보고서로 그대로 복사하지 않는다.

공개·납품 전에는 다음 항목을 검토한다.

1. 사용자명·호스트명·실제 설치 경로를 `<REDACTED_PATH>` 등으로 치환한다.
2. 요청 내용·토큰 ID·장치 UUID는 재현·검증에 필요한 범위만 남긴다. 치환했다면 규칙을 기록한다.
3. 원자료는 보존하고 공개 사본을 따로 만든다. 성능 수치·무결성 오류를 숨기거나 잘라내지 않는다.
4. 외부에서 받은 CSV를 스프레드시트로 열 때 수식 셀을 실행하지 않는다. 현재 CSV 출력은 수식 이스케이프 기능이 아니다.
5. 실제 fixture는 값 변경 없이 식별 경로만 치환하며, 합성 fixture는 별도 디렉터리로 구분한다.
6. 원본 trace 대신 `operators.csv`, `operators.md`, 유형 집계를 제공한다. 미수집·부분 집계 상태를 유지한다.

보존 기간·자료 책임자·삭제 승인 절차는 프로젝트 운영자가 정해야 하며 이번 코드에서 확정하지 않았다.
공개 사본 삭제 시 원본·백업·배포 사본을 함께 점검한다. 자동 영구 삭제 기능은 제공하지 않는다.

## 4. 도구 이미지·trace 처리

`report_figures.py`는 내부 CSV·JSON을 읽고 matplotlib 그림을 PNG로 저장한다.
`operator_stats.py`는 JSON/gzip/PB trace를 분석하며 이미지 파일을 읽지 않는다.
Pillow 12.3.0 잔여 경고는 이 사용 범위와 Python 3.10 제약 하에 기록한 예외다.
외부 이미지·폰트·trace를 받는 서비스로 확장하면 현재 노출 판단을 재사용하지 않는다.
대용량 또는 손상된 trace는 메모리·CPU를 소모할 수 있으므로 신뢰하는 측정 파일만 분석한다.

## 5. 사고·이상 자료 대응

민감 정보 유출이나 비신뢰 입력이 의심되면 외부 공유를 중지하고 접근 권한·수집 경로를 확인한다.
실행 ID·커밋·파일 해시·발생 시각·확인된 영향을 남기되 민감 본문을 이슈에 붙이지 않는다.
원본 증거와 공개용 치환 사본을 구분하고, 운영 책임자의 절차에 따라 통지·삭제·재발 방지를 수행한다.
잔여 확인: all-smi 외부 접근 차단 실측, 결과 디렉터리 권한, SDK 부가 통신, 보존·공개 승인 절차.
